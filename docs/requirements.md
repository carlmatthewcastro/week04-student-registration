# System Requirements

## Minimum requirements

- PHP 8.2+
- Composer
- Node.js 18+
- npm
- A supported database such as SQLite or MySQL
- Git for version control

## Recommended development environment

- Laravel Sail or a local PHP environment
- VS Code with PHP and Laravel extensions
- Browser for testing the registration flow
- GitHub repository access for version tracking and collaboration

## Operational notes

The project assumes a configured environment for database access and file storage. Uploaded profile pictures require a writable `public/storage` path after the Laravel storage link is created.
