# Screenshot Documentation

This project includes screenshots that document the application workflow from form entry to final profile display.

## Included Views
- registration form
- validation error feedback
- successful registration result
- flash message output
- uploaded profile picture
- student profile page
- project structure in VS Code
- GitHub repository overview

## Purpose
The screenshots provide evidence of the final result and help explain how the application behaves in a real environment.

## Maintenance
When the UI is updated, the screenshots should be refreshed to match the current interface and maintain accurate documentation.
