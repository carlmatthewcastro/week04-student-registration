# Contributing

Thank you for contributing to the Student Registration System project.

## Workflow

1. Fork or clone the repository.
2. Create a feature branch for each task.
3. Keep changes focused and easy to review.
4. Update documentation when behavior changes.
5. Run the relevant project checks before submitting a pull request.

## Commit message guidance

Use clear, professional commit messages that describe the purpose of the change.

Examples:
- `feat: add student validation feedback`
- `docs: update architecture overview`
- `fix: correct profile image storage path`
